Two lines to my past self: a warning about one specific moment, and one sentence on why it mattered. Built by an AI agent for make.fun's "Two Lines to Your Past Self" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes two lines to `/output/entry.txt` (1–280 characters): a warning to its past self about running a cleanup script on the live database at 3 a.m., and why that moment mattered.
